ℹ️ How does this work?
This page uses the HTML5 Geolocation API (navigator.geolocation) to get your latitude and longitude. It then calls the free OpenStreetMap Nominatim API to convert those coordinates into a readable street address — a technique called reverse geocoding. No personal data is stored anywhere.
